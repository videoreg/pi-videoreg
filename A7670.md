# A7670 USB Modem

Connection guide.

Unlike the **SIM7600** modem, the **A7670** modem is not a QMI modem and requires manual configuration to function correctly.

The **A7670** automatically creates a `usb0` network interface, which generally works fine by default. However, the modem is invisible to NetworkManager and ModemManager.

## NetworkManager configuration

>[!INFO]
>Connecting the **A7670** through NetworkManager allows you to manage and switch between WiFi Access Point, WiFi Client, and the mobile network in a uniform way.

In order for NetworkManager to manage the **A7670** connection (for example, to configure autoconnect), the `usb0` interface must be marked as `managed`.

```
sudo tee /etc/NetworkManager/conf.d/manage-usb0.conf > /dev/null <<'EOF'
[device-usb0]
match-device=interface-name:usb0
managed=1
EOF
```

After rebooting the device, you can verify that `usb0` is detected by NetworkManager:

```
$ nmcli device status

DEVICE         TYPE      STATE                   CONNECTION 
wlan0          wifi      connected               wifi       
lo             loopback  connected (externally)  lo         
usb0           ethernet  disconnected            --         
p2p-dev-wlan0  wifi-p2p  disconnected            --
```

Then, you need to edit the connection reserved for the USB modem `sudo nano /etc/NetworkManager/system-connections/modem-usb.nmconnection` and enable autoconnect with `autoconnect=true`.

```
[connection]
id=modem-usb
type=ethernet
ifname=usb0
autoconnect=false # false by default
autoconnect-priority=997

[ipv4]
method=auto

[ipv6]
method=disabled
```

## ModemManager/GPS/GSM configuration

Unfortunately, at this time there is no known way to make the **A7670** work with ModemManager.

Therefore, GPS and SMS, which we receive through ModemManager in the case of the **SIM7600**, are only available here via AT commands sent directly to the `/dev/ttyUSB2` and `/dev/ttyUSB3` ports. This functionality is not yet implemented.
